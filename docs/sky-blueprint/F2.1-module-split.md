# F2.1 (প্রথম অংশ) — স্টাইলশিট আলাদা করা, সাইজ-বাজেট খোলা

**তারিখ:** ২০২৬-১১-০২ · **কাজ:** F2.1 (ai-agent-chat.js মডিউলে ভাগ) — প্রথম ধাপ

## সমস্যা: দেয়ালটা ছিল সাইজ-বাজেট, আর সেটা F2-এর সব কাজ আটকে রেখেছিল

`p32-size-budget.test.mjs` ফাইলে **হার্ড সিলিং** বসিয়ে রাখে এবং রিপোর নিয়ম
স্পষ্ট: **"সিলিং কখনো বাড়াবে না — বরং পরিবর্তনটা ছোট করো।"**

পরিমাপ: `ai-agent-chat.js` ছিল **১৪৫,৯৫০ বাইট**, সিলিং **১৪৬,০০০** —
মানে হাতে ছিল মাত্র **৫০ বাইট**। F2.2 (প্রোগ্রেস টাইমলাইন), F2.3 (আপলোড UI),
F2.4 (KaTeX) — কোনোটাই ৫০ বাইটে হয় না। তাই F2-এর প্রথম কাজটাই ছিল জায়গা করা।

## যা করা হলো

ফাইলের ভেতরে সবচেয়ে বড় নিষ্ক্রিয় অংশটা ছিল **২৯ কিলোবাইটের CSS** —
৩৫৬টা সিলেক্টর, শূন্য ইন্টারপোলেশন, অর্থাৎ খাঁটি ডেটা। সেটা সরানো হলো
`sky-chat.css`-এ, আর চ্যাট প্রথমবার খোলার সময় সেটা `<link>` দিয়ে লোড হয়।

- আগে: `const CSS = \`...\`` ইনলাইন + `st.textContent = CSS`
- এখন: `st.rel='stylesheet'; st.href='sky-chat.css?v=skyv1'`
- একই লেজি-লোড ছাঁচ যা সাইনআপ ফ্লো আগেই ব্যবহার করে (`account-access.js`)
- `st.id` আগের নামটাই রাখা হয়েছে (`skyCss`), তাই যারা ওটা খোঁজে তাদের কিছু বদলায় না

## কেন এটা নিরাপদ, অনুমান নয় — মাপা

1. **প্রতিটা সিলেক্টর `#app.sky`-এ সীমাবদ্ধ** — স্ক্রিপ্ট দিয়ে ৩৫৬টা সিলেক্টর
   যাচাই করা হয়েছে; শূন্যটাও বাইরে যায় না। তাই গ্লোবাল স্টাইলশিট হলেও
   অ্যাপের বাকি অংশে হাত পড়ে না।
2. **ইন্টারপোলেশন শূন্য** (`${` = ০) — অর্থাৎ খাঁটি স্ট্যাটিক টেক্সট, রানটাইমে
   কোনো মান বসে না, তাই কপি করতে কিছু হারায় না।
3. **`sw.js`-এর APP_SHELL-এ যোগ + ডাইজেস্ট রিজেনারেট** — নইলে অফলাইনে
   শিটটা ক্যাশে থাকত না এবং UI রঙহীন পড়ত। `scripts/sw-manifest.mjs` চালানো
   হয়েছে; idempotent (দুবার চালালেও একই হ্যাশ)।

## ফলাফল

- `ai-agent-chat.js`: **১৪৫,৯৫০ → ১১৭,৩৭৯ বাইট** (−২৮.৬ কিলোবাইট)
- সিলিং নিয়ম মেনে **নামানো** হলো: **১৪৬,০০০ → ১২১,০০০** (আজকের আকারের ~৩% উপরে)
- প্রথম লোডে অ্যাপ **ছোট** হয়: CSS আগে প্রতি ভিজিটে JS বান্ডলের সাথে
  ডাউনলোড হত, এখন ব্রাউজার একবার ক্যাশ করে নেয়
