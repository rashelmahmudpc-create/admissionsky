# F1.4 — JSON আউটপুট (the structured envelope reaches the caller)

**তারিখ:** ২০২৬-১১-০১ · **কাজ:** প্রতিটা উত্তরের সাথে যন্ত্র-পাঠ্য রূপ পৌঁছানো

## যা ছিল

`response-validator.js` M5 থেকেই একটা structured envelope বানায়:
`{ version, type, message, insights, recommendations, actions, confidence }`।
চ্যাট রুট ওটা JSON body আর `done` event — দুই জায়গায় বসাত।

## দুটো ফাঁক

1. **guidance উত্তরে envelope ছিলই না।** OTP/পাসওয়ার্ড-নীতির লেখাটা হাতে বানানো
   prose, অথচ বাকি সব উত্তরে envelope যেত।
2. **ক্লায়েন্ট envelope পড়ে ফেলে দিত।** `done` event পার্স করত, envelope
   দেখত, তারপর ছুঁড়ে ফেলত — তাই UI-এর সব কলার শুধু prose পেত।

## যা করা হলো

- guidance উত্তরের envelope এখন `buildEnvelope` দিয়েই বানে — **একই বিল্ডার**,
  তাই দ্বিতীয় একটা হাতে-বানানো envelope আর জন্মাতে পারবে না।
- ক্লায়েন্ট envelope রাখে আর কলারকে ফেরত দেয় (`structured`), কিন্তু
  **ঐচ্ছিক** — পুরনো সার্ভার কিছু না পাঠালে null থাকে, আগের আচরণ অটুট।

## একটা সচেতন সিদ্ধান্ত

guidance-এর লেখাটা সিস্টেমের নিজের নীতি-বাক্য, মডেলের উত্তর নয়। তাই ওটা
**আবার স্ক্যান করা হয় না** — করলে একটা সঠিক নির্দেশনা ভুল-নোটিশ দিয়ে
বদলে যেতে পারত। `blocked` শুধু `type: guidance` বাছতে বসে।
